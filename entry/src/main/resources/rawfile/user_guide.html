使用教程

从登录到安装，四步完成 HAP 调试装机

1登录华为账号

在首页顶部找到「华为账号」卡片，点击右侧的「登录账号」按钮。

登录账号

系统会自动打开浏览器，跳转到华为开发者授权页面。请在浏览器中完成登录与授权操作。

提示：登录采用 DevEco IDE 授权通道，授权完成后会自动回调本应用，无需手动复制。若长时间未回调，请检查浏览器是否正常打开，或重试一次。

登录成功后，首页顶部会显示您的 uid，按钮文字变为「更换账号」。如需切换账号，再次点击即可重新走浏览器授权流程。

2连接无线调试

登录成功后，「设备」卡片会自动出现。点击右侧的「无线调试」按钮，打开连接抽屉。

无线调试

2.1在手机上开启无线调试

  1. 进入手机「设置 → 系统 → 开发者选项」
  2. 打开「无线调试」开关
  3. 点击「无线调试」进入详情页，查看底部的 IP 地址与端口（形如 192.168.1.100:5555）

2.2在本应用中连接

在弹出的连接抽屉中，分别填入手机上显示的 IP 和端口：

  • IP 地址：例如 192.168.1.100
  • 端 口：例如 5555

点击「连接」，等待状态栏显示「已连接」。

提示：手机与电脑需在同一局域网。若连接失败，请确认手机无线调试已开启、IP 与端口正确、防火墙未拦截。可在「更多 → 自动无线调试端口」开启自动重连。

3选择安装包

连接成功后，「软件安装包」卡片会自动出现。点击右侧的「选择」按钮。

选择

在文件选择器中找到您的 .hap / .hsp / .app 安装包文件并确认。

提示：也可以在输入框中粘贴下载地址（http://.../app.hap），点击「下载」自动获取安装包。选包后会自动识别 bundle 名称与大小。

选中后，卡片会显示包名与文件大小，按钮文字变为「更换」。如需更换安装包，再次点击即可重新选择。

4调试安装 / 已签名安装

前三步完成后，页面底部会出现两个安装按钮：

4a开始调试（自动签名）

开始调试（自动签名）

点击此按钮，应用会自动完成签名并安装到设备。适合需要调试的未签名 HAP 包。

  • 自动使用内置签名材料（证书 / 密钥库 / Profile）
  • 签名完成后立即推送安装，无需手动操作
  • 若 Profile 绑定的包名与目标包不一致，会自动切换或申请对应的调试 Profile
提示：自动签名使用内置签名材料，开箱即用，无需额外配置。

4b直接安装（需已签名）

直接安装（需已签名）

点击此按钮，应用会跳过签名步骤，直接将已签名的 HAP 安装到设备。适合已有有效签名的安装包。

  • 安装包必须已通过华为 CA 链签名，否则系统会拒绝安装
  • 若安装本应用自身（HapInstaller），安装后会自动重启
  • 覆盖安装时会弹出确认弹窗，点击「继续安装」即可
提示：安装失败时请检查日志中的提示信息。常见原因：设备未连接、HAP 未签名、Profile 的 bundle-name 或 UDID 与目标包不匹配。

如需查看更多功能，请前往「更多」页面
